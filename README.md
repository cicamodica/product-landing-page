# Pulse Smartwatch Landing Page
Landing page responsiva desenvolvida para apresentar a linha fictícia de smartwatches Pulse.  
O projeto foi criado com foco em prática de desenvolvimento front-end, UI Design e construção de interfaces modernas, utilizando conceitos de responsividade, hierarquia visual e experiência do usuário.

# Sobre

O Pulse é uma landing page moderna voltada para divulgação de produtos tecnológicos wearable, inspirada em marcas premium do mercado.

A proposta do projeto é simular uma experiência real de showcase de produtos, apresentando diferentes modelos de smartwatches com design clean, visual minimalista e foco em usabilidade.

O projeto foi desenvolvido utilizando a abordagem *Mobile First*, garantindo uma experiência consistente em diferentes tamanhos de tela.

# Como executar o projeto
1. Clone o repositório *git clone https://github.com/cicamodica/product-landing-page.git*

2. Acesse a pasta do projeto *cd product-landing-page*

3. Execute o projeto

- Basta abrir o arquivo index.html no navegador.

- Ou utilize a extensão Live Server no VS Code para uma melhor experiência durante o desenvolvimento.
